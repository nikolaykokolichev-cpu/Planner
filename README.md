# Планер

Задачи + календар, синхронизирани между Mac, Windows и iPhone. Инсталира се като приложение (PWA), работи и офлайн.

## Файлове
- `index.html`, `style.css`, `app.js`, `logic.js`, `store.js` — приложението (логика и хранилище са отделни)
- `tests/` — тестове на чистата логика: `node --test tests/logic.test.mjs`
- `firebase-config.js` — тук се слагат ключовете от Firebase
- `firestore.rules` — правила за сигурност (всеки вижда само своите данни + мостът за асистент)
- `manifest.json`, `sw.js`, `icons/` — инсталиране и офлайн режим

## Без Firebase (локален режим)
Докато `firebase-config.js` съдържа `PASTE_...`, приложението работи, но данните са само в това устройство.

## Настройка на синхронизацията (еднократно, ~10 мин.)
1. console.firebase.google.com → **Add project** (Analytics не е нужен).
2. **Build → Authentication → Get started → Google → Enable** (избери имейл за поддръжка).
3. **Build → Firestore Database → Create database** (production mode, регион `eur3`).
4. В Firestore → **Rules** постави съдържанието на `firestore.rules` → **Publish**.
5. **Project settings → General → Your apps → Web (`</>`)** → регистрирай приложение → копирай `firebaseConfig` във `firebase-config.js`.
6. **Authentication → Settings → Authorized domains** → добави домейна, на който ще е публикувано (напр. `ТВОЕТО-ИМЕ.github.io`).

## Публикуване (GitHub Pages)
Repo → **Settings → Pages → Deploy from a branch → `main` / root**. Линкът е `https://ТВОЕТО-ИМЕ.github.io/planner/`.

## Инсталиране
- **iPhone:** Safari → Share → *Add to Home Screen*.
- **Mac/Windows:** Chrome или Edge → иконата „Инсталирай" в адресната лента.

## Известия
Бутон 🔔 → разреши. Напомнянията се показват, докато приложението е отворено (или на заден план). Истински push при затворено приложение изисква сървърна част (Cloud Functions) — следваща стъпка.

## Фаза 2: ритуали и навици
- **Топ 3 за деня:** ★ до задача или подсказката сутрин (до 14:00).
- **Вечерна рекапитулация:** 🌙 или подсказка след 21:00 (часът се сменя в „Навици → Настройки"). Преглед на деня, „→ Утре", избор на Топ 3 за утре, победа на деня.
- **Фокус (Помодоро):** 25/5, всяка 4-та почивка е дълга (15). На iPhone таймерът може да закъснее, ако приложението е на заден план.
- **Навици:** 2–3 малки навика, „X от последните 7 дни", без наказание за пропуск.

## Аспазия и мост за външен асистент
**Категория „Аспазия"** (розов цвят, отделен таб във филтъра). Отворените, неповтарящи се задачи „Аспазия" с минала дата автоматично минават за днес — при отваряне на приложението и при смяна на деня. Броят прехвърляния се вижда в реда на задачата като `⇢N`. Прехвърлянето чака данните да дойдат от сървъра (не само от кеша), за да не презапише по-нова версия от друго устройство.

**Мостът** позволява на външен асистент да добавя и отмята задачи, без достъп до профила ти:
- При първо влизане с Google приложението създава таен ключ (43 знака, 256 бита) и го пази в `users/{uid}/settings/bridge`. Виждаш го и го копираш от **Навици → Настройки → Мост за асистент**. Ключът не е в хранилището (GitHub).
- **Входяща кутия** `bridge/{ключ}/inbox/{id}` — асистентът създава документ:
  `{ op: "add"|"update"|"done"|"undone"|"delete", taskId, title, notes, date: "ГГГГ-ММ-ДД", time: "ЧЧ:ММ", cat, prio: 1|2|3, at: ISO }`.
  Задължителни са `op` и `taskId` (букви, цифри, `-`, `_`; до 128 знака); за `add` — и `title`. Лимити: заглавие 200, бележки 2000 знака.
  Когато си влязъл, приложението прилага операцията върху `users/{uid}/tasks/{taskId}` и изтрива документа. `add` без дата/категория → днес / „Аспазия". Повторно получена операция не дублира задача (`taskId` е ключът; `done`/`undone` са идемпотентни; `update` на несъществуваща задача се пропуска).
- **Статус** `bridge/{ключ}/status/{taskId}` — огледало на всяка задача „Аспазия": `{ title, date, time, done, doneAt, moved, updated }`. Изтрива се, когато задачата се изтрие (или смени категорията).
- Операциите се прилагат само докато приложението е отворено някъде (телефон или компютър).

Пример (Firestore REST, без вход — само с ключа):
```
POST https://firestore.googleapis.com/v1/projects/nk-planner-f2a67/databases/(default)/documents/bridge/КЛЮЧ/inbox
{ "fields": { "op": {"stringValue": "add"}, "taskId": {"stringValue": "asp-20261112-1"},
  "title": {"stringValue": "Обади се на счетоводителя"}, "date": {"stringValue": "2026-11-13"},
  "prio": {"integerValue": "1"}, "at": {"stringValue": "2026-11-12T08:00:00Z"} } }
GET  https://firestore.googleapis.com/v1/projects/nk-planner-f2a67/databases/(default)/documents/bridge/КЛЮЧ/status
```
След промяна на `firestore.rules` ги постави отново във Firebase конзолата → Firestore → Rules → Publish.
